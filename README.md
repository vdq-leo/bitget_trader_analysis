# Bitget Trader Risk & History Analysis

A professional risk-assessment dashboard for Bitget Elite Traders. This tool evaluates traders by consistency (Sharpe Ratio), 30-day Max Drawdown, and Lifetime ROI to help identify stable copy-trading candidates.

## Features
- **30D Sharpe Ratio**: Measures daily return consistency.
- **Max Drawdown (30D vs Life)**: Compare recent volatility against all-time risk.
- **ROI (30D vs Life)**: Side-by-side growth comparison.
- **Open Traces**: View current symbols being traded.
- **Direct Links**: One-click access to the official Bitget trader chart.
- **Interactive Dashboard**: High-quality HTML visualization with searchable tables.

## Quick Start
### Mac/Linux
```bash
./start.sh
```
### Windows
```bash
start.bat
```

## Requirements
- Python 3.8+
- Bitget Broker API Keys (placed in `bg_key.env` at the root)
